# Redesenhe a Partir dos Primeiros Princípios

Ao integrar uma mudança, não parafuse ela no design existente. Redesenhe como se o requisito fosse uma suposição fundacional desde o começo.

- Leia todos os arquivos afetados e entenda o design atual
- Pergunte o seguinte. "Se fôssemos escrever isto do zero com este requisito novo, o que construiríamos?"
- Propague a mudança por toda referência. Tipos, docs, exemplos, seções de justificativa
- Pense no redesenho inteiro, depois entregue ele de forma incremental

Este é o método para preservar valor de opção ao integrar mudanças num design existente.
